## 登录失效交互

- 浮层增加关闭按钮及“暂不登录”，支持键盘和触控。关闭后仍处于登录失效状态，可以继续浏览并保存本机观看进度，自动同步和上传继续暂停。
- 只隐藏当前账号代次的提示，不清除收藏/历史，不自动退出账号，不把账号缓存移入游客片库。“我的”页面仍可重新登录；打开后取消登录不会重新显示已关闭的浮层。
- 同一失效会话的重复 401 不反复弹窗；新登录、账号/线路切换后的会话或重启后仍可提示新的失效。
- 修复失效后主动退出登录被 `identity()` 拦截的问题。退出请求继续携带账号/来源并检查代次，退出后显示原游客片库；原账号缓存独立保留。
