# HGhubX 2.1.2：上游同步与可关闭的登录失效提示

从 fork 2.1.1（`5b6d62a`）合入上游 `7c3d409`、`1d7b825` 两个提交，上游基线锁定为 `1d7b825d2b36670c610bf8e8bfc85d6e65069097`。

## 合并内容

- 采用上游标签页实现：短剧与帖子分别查询、分页和重试，帖子接口使用标签名称，标签分数注明“热度”。包含后续 `MediaCard` 导入修复。
- 采用上游播放器尺寸识别修复：测量结果与当前账号、线路、集数和播放源绑定，忽略过期尺寸，移动端尺寸未知时优先显示完整画面。
- 版本字段冲突统一为 2.1.2，Android versionCode 为 2001002。Bundle ID 仍为 `com.hghubx.app`，没有升级依赖。
- NAT64 网络策略、旧接入地址迁移、片库迁移、401/403 区分及账号代次保护保留，相关核心文件与合并前一致。`api.ts` 和原生命令注册同时保留新增帖子接口与 fork 功能，历史文档不删除。

## 登录失效交互

- 浮层增加关闭按钮及“暂不登录”，支持键盘和触控。关闭后仍处于登录失效状态，可以继续浏览并保存本机观看进度，自动同步和上传继续暂停。
- 只隐藏当前账号代次的提示，不清除收藏/历史，不自动退出账号，不把账号缓存移入游客片库。“我的”页面仍可重新登录；打开后取消登录不会重新显示已关闭的浮层。
- 同一失效会话的重复 401 不反复弹窗；新登录、账号/线路切换后的会话或重启后仍可提示新的失效。
- 修复失效后主动退出登录被 `identity()` 拦截的问题。退出请求继续携带账号/来源并检查代次，退出后显示原游客片库；原账号缓存独立保留。
