## 收藏和观看记录

- 保留 1.3.0/更早版本到 `hghubx_app_v1` 的合并、备份、去重、最新进度及一次性迁移标记。
- 2.0.0 已迁移数据直接读取，不会再次导入旧备份、复活取消的收藏或已删除的历史。
- 上游新账号模型将游客和账号数据隔离。原本地记录作为游客片库保留；登录显示当前站点/账号记录，退出登录恢复本地记录。不会隐式把游客收藏和历史上传到某个账号。
- 账号缓存按 origin 与用户 ID 区分；旧请求不能覆盖新账号。同步失败保留已有缓存，游客片库写入不能回滚播放偏好。
- `pnpm test:storage-migration` 新增账号切换、迟到响应、离线、退出、重启和偏好保留测试；可使用 `HGHUBX_MIGRATION_SEED` 指向本地私有片库快照，验证真实数据副本，不提交个人数据。
